Title: ADR 01: Development framework 

Status: Proposed

Context: We need to build a cross-platform mobile app that works locally, prevents crashes, and meets the course requirement of using the Bootstrap design system.

 Decision: We will build the app using React Native with Expo, written entirely in TypeScript, and use the react-native-bootstrap-styles library. 

Consequences: Setup and development become much faster, catching errors early becomes easier, and applying Bootstrap designs to a mobile interface is simple.
