Title: ADR 01: Development framework  

Status: Proposed 

Context: We need to build a cross-platform mobile app that works locally, prevents crashes, and meets the course requirements of using the Bootstrap design system. 

 Decision: We will build the app using React Native with Expo, written entirely in TypeScript, and use the react-native-bootstrap-styles library.  

Consequences: We stick to the exact tools we learned in our course, making the build process predictable. Else than using bootstrap styling for mobile, this would feel somewhat new to us. Though we must follow it for the requirement, and it's good to be familiar with.
